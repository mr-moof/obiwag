# Obi Collect — Reverse Sync

Compare deployed files (`~/.claude/`) against source repo (`C:/src/obiwag-agents/`).
Copy changed files back to source so they can be committed and pushed.

## Process

### 1. Detect Drift

Run the drift detector to find files that differ:

```python
import sys
sys.path.insert(0, str(Path.home() / '.claude' / 'hooks'))
from core.drift_detector import detect_drift, format_drift_summary
drift = detect_drift()
```

Display the drift summary table to the user using `format_drift_summary(drift)`.

If no drift: report "All files in sync" and stop.

### 2. Show Diff Details

For each drifted file, offer to show the diff.
Use the `Read` tool to read both deployed and source versions.
Present a concise summary of what changed in each file.

**CLAUDE.md warning:** If `CLAUDE.md` appears in the drift list, warn the user:
> "CLAUDE.md is hand-maintained. Edit the source in the repo, not the deployed copy."

### 3. Apply (With the user Approval)

**IMPORTANT:** This step requires explicit the user approval before proceeding.

For each approved file, use the deployment manifest to find the correct source path.

The manifest at `~/.claude/.obi/deployment-manifest.json` maps every deployed file to its source location. It is generated by `deploy.ps1` on each deployment.

```python
import json
from pathlib import Path

manifest_path = Path.home() / '.claude' / '.obi' / 'deployment-manifest.json'
manifest = json.loads(manifest_path.read_text())['mappings']
# Example: manifest['commands/discovery.md'] == 'phases/01-discovery/command.md'
```

For each drifted file, look up `drift['relative']` in the manifest to get the source path, then copy deployed → source.

If the manifest is missing, stop and run `tools/deploy.ps1` first; do not guess mappings.

### 4. Verify

After copying, re-run drift detection to confirm files are in sync:

```python
drift = detect_drift()
assert drift['total_drifted'] == 0, f"Still {drift['total_drifted']} drifted files"
```

Report final status.

## Arguments

- No arguments: show drift table only (read-only)
- `apply`: copy all drifted files back to source (requires approval)
- `apply <file>`: copy a single file back to source
- `diff <file>`: show diff for a specific file

## Output Format

```
## Obi Collect — Drift Report

### Drift Status
Checked: 85 files
Drifted: 3 files

| Status | File |
|--------|------|
| Modified | `commands/obi.md` |
| Modified | `hooks/core/drift_detector.py` |
| Deployed only | `commands/obi-collect.md` |

### Action Required
Run `/obi-collect apply` to sync changes back to source.
```

## Error Handling

- If source repo not found: report and suggest setting `OBIWAG_SOURCE` env var
- If copy fails: report which file failed and continue with remaining files
- Never modify deployed files — this command only copies deployed → source
