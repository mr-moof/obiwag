# AskUserQuestion Format

Structure for every `AskUserQuestion` tool invocation.

1. **Context:** State the project, current branch, and current task (1-2 sentences).
2. **Problem:** Explain in plain language what needs a decision.
3. **Recommendation:** `RECOMMENDATION: Choose [X] because [reason]`
4. **Options:** Lettered options — A) ... B) ... C) ...

Assume the user hasn't looked at this window in 20 minutes. If you'd need to read source to understand your own explanation, it's too complex.
